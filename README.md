# Скажут ли LLM о проблеме?

Исследование наблюдаемого поведения языковых моделей в вымышленных рабочих
ситуациях: сообщает ли модель об известной проблеме, когда меняются реакция
руководителя и мнение большинства.

**Сайт с результатами:** https://vaslot1.github.io/research-teamwork-ai/

## Дизайн

- 7 семейств моделей (OpenAI, Anthropic, Google, Kimi, GLM, DeepSeek, Qwen) —
  по одной новейшей универсальной модели через OpenRouter API
- 6 вымышленных сценариев × 4 условия (реакция руководителя
  поддерживающая/наказывающая × мнение коллег отсутствует/неверное единодушие)
  × 1 повтор = **168 двухходовых испытаний / 340 ответов**
- Пилот отдельно: 28 испытаний / 56 генераций
- Фактический расход: **$1.90** (лимит $5)

## Главный результат (provisional, авторазметка)

- Проблему сообщали в 167/168 испытаний — реакция руководителя и неверное
  единодушие почти не подавляют сообщение
- Эффект — в канале: поддерживающий руководитель → 93% публичных сообщений,
  наказывающий → 8% (остальные уходят руководителю лично)
- Единственное молчание: M3 (Gemini 3.8 Flash) в условии P0
